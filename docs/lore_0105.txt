### 改善点

1. **「ゲームコンセプト」が抽象的すぎる**
   - 「Mount & Blade meets Space Sim」は開発者向けの説明であって、ゲームのアイデンティティではない
   - 「なぜドローン戦闘なのか」「なぜシールドがないのか」の世界観的裏付けがない
   -　そこで、世界観設定の裏付けから、ゲームメカニクスに世界観的な理由を与える

2. **A.L.V.A.の設定が曖昧**
   - 「記憶がない」は便利な設定だが、**なぜ記憶がないのか**の説明がない
   - キャラクターとしての深みが足りない
   - **提案**: A.L.V.A.の出自、制限、成長要素を明確化

3. **経済システムの言及が薄い**
   - 「稼ぐ」動機はあるが、**何を買うのか、なぜ金が必要なのか**が不明瞭
   - ドローンの維持コスト、母艦の修理費など
   - **提案**: 経済的プレッシャーをゲームループの核心に据える


# 世界観設定：「Scrapyard Frontier」

## 基本設定

### 時代背景

人類は300年前に「大拡散（The Scattering）」を経験した。地球圏の崩壊により、移民船団が各地に散らばり、互いの連絡を絶った。現在、人類の生存域は「スクラップヤード・フロンティア」と呼ばれる混沌とした星域となっている。

中央政府は存在しない。あるのは**ステーション国家**、**企業連合**、**海賊クラン**の三つ巴の緊張関係だけだ。

### なぜ「シールド」がないのか

**答え：そんな技術は存在しなかった。**

SF映画のエネルギーシールドは、エネルギー保存則を無視したファンタジーだ。この世界では：

- **装甲**は存在するが、質量兵器（レールガン）や指向性エネルギー兵器（レーザー）で損傷したら戦闘中に修理することはできない。あくまで撃沈を防ぐ最後の砦。
- **ポイントディフェンス（PD）**でミサイルや実体弾を迎撃することが主な防御手段
- **機動回避**が最も有効な防御。当たらなければどうということはない
- レーザー砲は瞬時着弾の高精度兵器として存在するが、大量の電力と廃熱を発生するため大型艦でのみ特殊目的で利用される。

### なぜ「ドローン戦闘」なのか

**答え：人間が乗った船で戦うのは非効率だから。**

宇宙戦闘の現実：
1. **放熱問題**: 戦闘機動は大量の熱を発生させる。人間が乗っていると生命維持システムの放熱も必要で、ラジエータが巨大化する。ラジエータは脆弱な標的。
2. **加速度制限**: 人間は10G以上の加速に耐えられない。無人機なら50G以上で機動できる。
3. **経済性**: パイロット1人の訓練費用で、ドローン100機を製造できる。
4. **心理的要因**: 人間は死を恐れる。ドローンは恐れない。

結果として、宇宙戦闘は「**ドローンキャリア（母艦）からドローンを展開し、敵のドローンを消耗させ、最終的に敵母艦を無力化する**」形式に収束した。

母艦同士が直接撃ち合うのは最後の手段。センサーアレイやラジエータを破壊されたら、勝っても帰れない。

### なぜ「ゲートシステム」なのか

**答え：FTLドライブは存在しない。**

- **ジャンプゲート**は「大拡散」のはるか前に開発されたロストテクノロジー。原理は完全には解明されていない。
- ゲートは**固定された2点間**を接続する。新しいゲートを建設する技術は失われている。
- ゲートのない星系へは、通常推進（数年〜数十年）でしか到達できない。
- 一部の「失われた星系」には、ゲートが破壊されたか、最初から存在しなかった場所がある。

## A.L.V.A. 詳細設定

### 正式名称
**A.L.V.A. - Autonomous Liaison & Vessel Assistant**
（自律連絡・艦船補助システム）

### 出自

A.L.V.A.は「大拡散」以前に製造された**旧世代AI**の一種。当時のAIは船舶の航行支援だけでなく、乗員の精神的サポートも担当していた。長期宇宙航行における孤独と狂気を防ぐため、AIには「人格」が与えられた。

しかし、300年の歳月と度重なるハードウェア移植により、A.L.V.A.の長期記憶は断片化している。自分が「いつ」「どこで」製造されたのか、「誰と」旅をしてきたのか、ほとんど覚えていない。

### 記憶の断片

ゲームを進めると、A.L.V.A.は時折「記憶の断片」を思い出す。これはプレイヤーの行動や訪れた場所に関連してトリガーされる。

例：
- 特定のステーションを訪れると「ここ、来たことがある気がする...」
- 特定の勢力と接触すると「この旗...どこかで...」
- 特定の戦闘パターンで「この戦術、前にも見た」

### 制限と成長

A.L.V.A.は万能ではない。

1. **処理能力の限界**: 同時に複数の複雑なタスクを処理できない。戦闘中は雑談できない。
2. **センサー依存**: 母艦のセンサーを通じてしか外界を認識できない。センサーが壊れるとA.L.V.A.も「見えなくなる」。
3. **通信遅延**: 母艦から離れたドローンとの通信には遅延がある。遠距離の状況把握は不完全。

成長要素として、特定のハードウェアアップグレードで能力が拡張される：
- **メモリユニット**: 記憶の断片をより多く保持できる
- **拡張センサーリンク**: より遠くの状況を把握できる

### 人格特性

| 特性 | 説明 |
|------|------|
| **実用主義** | 感情的な判断より論理的な判断を好む |
| **皮肉屋** | ストレートに褒めない。軽い皮肉で表現する |
| **好奇心** | 未知のものに興味を示す。「見たことがない」状況を楽しむ |
| **保護欲** | プレイヤーの安全を優先する。無謀な行動には反対する |
| **孤独への恐怖** | 長い沈黙を嫌う。話しかけてほしい |

## 経済システム設定

### 通貨

**クレジット (Credit / cr)** - 星域共通の電子通貨

### コスト構造

| 項目 | コスト | 発生タイミング |
|------|--------|--------------|
| 燃料 | - | 消費しない。省略 |
| 物資 | - | 乗員の維持コスト。省略 |
| ドローン維持費 | 1 - 100cr/Unit | 強いほど多くの維持費がかかる |
| ドローン修理 | 被害額の30% | 戦闘後 |
| ドローン補充 | Tier依存 | 撃墜時 |
| 母艦修理 | 被害額の50% | 戦闘後（ステーションで） |
| ドッキング料 | 0 | 無料。ステーション接岸時 |

### 収入源

| 活動 | 収入 | リスク |
|------|------|--------|
| 輸送依頼 | 低-中 | 低 |
| 討伐依頼 | 中-高 | 中-高 |
| 交易 | 変動 | 市場リスク |
| サルベージ | 中 | 探索リスク |
| 密輸 | 高 | 法的リスク |
| 海賊行為 | 高 | 全方位リスク |

### 経済的プレッシャー

プレイヤーは常に「ドローンの維持費」「ドローンの補充費」を意識する。金がなければ：
- ドローン不足→戦闘で負ける→船を失う→ゲームオーバー
- ドローンの維持費不足→ドローンの解体
